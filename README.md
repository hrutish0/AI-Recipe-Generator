# AI Recipe Generator

A responsive recipe web application that helps users discover recipes and generate customized recipes using the ingredients they already have.

The application combines the **TheMealDB API** for recipe discovery with the **Google Gemini API** to generate AI-powered recipes based on available ingredients.

# Features

- Search for recipes by meal name
- Browse recipe cards with:
- Recipe name
- Cuisine/area
- Category
- Recipe image
- View complete recipe details
- Enter available ingredients
- Generate customized recipes using Google Gemini AI
- AI-generated:
  - Recipe name
  - Description
  - Ingredients with quantities
  - Cooking instructions
  - Optional ingredients
  - Ingredient substitutions
- Responsive design for desktop and mobile devices
- API keys securely stored using environment variables
